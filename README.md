# Luciene Ribeiro | Biomédica Esteta

Site expositor de estética e biomedicina com login, cadastro local, protocolos em destaque e agendamento de avaliações.

## Como testar

Opcoes:

- Abra o arquivo `index.html` no navegador.
- Para testar por `localhost`, execute `powershell -ExecutionPolicy Bypass -File .\serve.ps1` e acesse `http://localhost:8000`.

## Acesso demo

- E-mail: `admin@expo.com`
- Senha: `123456`

Os usuarios e agendamentos ficam salvos no `localStorage` do navegador. Para uma versao em producao, o proximo passo e ligar o login e os agendamentos a um backend com banco de dados.
